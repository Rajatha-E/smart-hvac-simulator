# 🌡️ Smart HVAC & Thermal Regulation Simulator

A real-time Python-based HVAC telemetry and thermal regulation simulator featuring a PID control loop, automated anomaly detection, and an interactive Streamlit web dashboard.

## 🚀 Features
* **PID Control Loop:** Dynamically calculates compressor and fan loads instead of using crude threshold switches.
* **Interactive UI:** Real-time data visualization and adjustable temperature setpoints via [Streamlit](https://streamlit.io/)[span_1](start_span)[span_1](end_span).
* **Telemetry Logging:** Exports real-time cycle data to a structured CSV log.
* **Anomaly Detection:** Scans telemetry logs to flag system faults and performance drops.

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (Web UI & Live Charts)
* **Pandas** (Data handling & CSV export)
